## Таблица атрибутов и настроек JSON

| Атрибут / настройка | Что делает | Пример |
|---------------------|------------|--------|
| `[JsonPropertyName("name")]` | Задаёт имя поля в JSON | `"name"` вместо `"Name"` |
| `[JsonIgnore]` | Поле не попадает в JSON | Пароли, внутренние заметки |
| `PropertyNamingPolicy.CamelCase` | Все поля в camelCase | `"realName"` вместо `"RealName"` |
| `JsonStringEnumConverter` | Enum как строка | `"Marvel"` вместо `0` |
| `WriteIndented = true` | JSON с отступами | Удобно при разработке |

## Вопросы для самопроверки

1. **Сериализация** – преобразование C#-объекта в JSON-строку.  
   **Десериализация** – обратное преобразование JSON-строки в C#-объект.

2. **Зачем нужен `[JsonIgnore]`?**  
   Пример: поле `InternalNotes` содержит служебную информацию (заметки разработчика, отладочные данные), которая не должна отправляться клиенту. Также для защиты паролей, токенов.

3. **Почему enum лучше сериализовывать строкой, а не числом?**  
   Число `0` неинформативно, а строка `"Marvel"` сразу понятна клиенту. При добавлении новых значений в enum числа могут сбиться, строки останутся читаемыми.

4. **Что изменилось после настройки CamelCase?**  
   Все поля в JSON стали с маленькой буквы: `realName`, `powerLevel` вместо `RealName`, `PowerLevel`. Это соответствует стандарту именования в JavaScript/JSON.
